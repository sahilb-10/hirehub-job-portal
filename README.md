# HireHub Job Portal

A full-stack job portal built using the MERN stack, where recruiters can post and manage job listings while candidates can explore available opportunities. The backend follows a clean MVC architecture and uses RESTful APIs with MongoDB for data management.

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- REST APIs
- Git & GitHub

## Backend Features Implemented

- Create Job API
- Get All Jobs API
- Get Single Job by ID API
- Update Job API
- Delete Job API
- MongoDB Atlas Integration
- MVC Architecture
- Environment Variable Configuration

## API Endpoints

| Method | Endpoint      | Description      |

| POST   | /api/jobs     | Create new job   |
| GET    | /api/jobs     | Fetch all jobs   |
| GET    | /api/jobs/:id | Fetch single job |
| PUT    | /api/jobs/:id | Update job       |
| DELETE | /api/jobs/:id | Delete job       |

## Project Status

Backend CRUD APIs for job management are completed successfully. Authentication, frontend integration, and job application features are currently in progress.
